# Project Reflection

### What I learned:
Building this in a high-pressure sprint taught me how to prioritize core logic (the audit engine) over flashy UI. I focused heavily on ensuring the math was correct.

### Challenges:
The biggest challenge was handling the "Hydration Mismatch" between server and client during the initial deployment on Vercel. I solved this by implementing a mounting check in the dashboard component.

### If I had more time:
I would integrate real-time API webhooks to pull live data directly from the OpenAI dashboard.
